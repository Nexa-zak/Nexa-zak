## 🚀 نکسا — پروژهٔ اصلی من · My Main Project

**نکسا** یک صفحهٔ تب جدید فارسی برای کروم است — با ویجت‌های کاربردی، والپیپرهای متحرک و یک اکوسیستم کامل اجتماعی.

<div dir="rtl" align="right">

### ✨ امکانات نکسا

| | |
|---|---|
| 🕰️ **ساعت و تقویم شمسی** | تقویم جلالی با تعطیلات رسمی |
| ✅ **بهره‌وری** | تسک‌ها، عادت‌ها، پومودورو با حلقهٔ پیشرفت، یادداشت‌ها |
| 💰 **دادهٔ زنده** | قیمت ارز و طلا (TGJU) + آب‌وهوا (Open-Meteo) |
| 🖼️ **والپیپر متحرک** | ۶ انیمیشن آفلاین + گالری ۵۴ والپیپر + فروشگاه آواتار با ۹۶ آواتار پینترست |
| 👤 **حساب کاربری** | ثبت‌نام/ورود با PBKDF2 + همگام‌سازی ابری (Cloudflare Workers + D1) |
| 💬 **شبکهٔ اجتماعی** | ادفرند، چت خصوصی با استیکرهای متحرک و گیف، بج Owner/Admin/Moderator |
| 🎛️ **پنل مدیریت** | آمار زنده، نمودار رشد، اعلان سراسری، لاگ فعالیت‌ها، گزارش پیام‌ها |
| 🔒 **حریم خصوصی** | داده‌ها فقط در مرورگر خود کاربر |
